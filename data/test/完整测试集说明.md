# 测试集构成

| 类型 | 文件 | 句数 | 格式 |
|------|------|------|------|
| ID | `test_positive.csv` | 70 | id, text, length, is_long, label=1, source |
| OOD | `test_negative.csv` | 60+? | id, text, length, is_long, label=0, source |
| 合并 | `test_full.csv` | 130+? | 同上 |

## OOD（分布外）样本细分
- **游戏内**（60句）：凯尔希/阿米娅/重岳/W 各15句，来源标记为角色名
- **游戏外**（未定）：哲学/学术/公文/口语... 数量灵活调整，来源标记为类别名

## 列说明
- `id`: 正例为原CSV中的id，负例为-1至-120
- `is_long`: length > 35 为True（与训练集划分一致）
- `source`: 角色名（凯尔希/阿米娅/重岳/W/Logos）或类别（哲学/学术/公文/口语...）
- `label`: 1=ID(逻各斯), 0=OOD
