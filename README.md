# Synecdoche
1.项目定义

核心问题：资源受限条件下，轻量级方法能否可靠地完成文本风格判别任务？它们的优势区间在哪里？

硬约束：

数据：游戏角色台词695句，短文本，无人工标注

算力：RTX 5060Ti单卡16G，无法加载7B以上模型

内容-风格解耦：不能让模型学到风格 = 关键词

无监督/自监督：不能在训练阶段引入人为预设标准（比如：“告诉“模型“我要吃饭”应该打0分，”今天天气真好“应该打1分）

先验知识：不涉及任何语言学专业训练

优势评价指标（用数学工具找最优）：

性能：在内容无关测试集上，与人类基准相关系数>0.7

效率：推理延迟，显存占用，复现难度

可解释性：每条预测能追溯到具体特征或训练样本

成本：本地零成本vs API每千句费用

技术门槛/学习成本：需要什么程度的ml知识？

蹭热点：低资源NLP，边缘计算，AI民主化

2.语料库构建

采集：爬台词（通过MediaWiki的API通道），清洗

内容-风格解耦：通过自动匹配和人工规则删除游戏专有词（这里实践过程中发现真没招了，只能几乎全靠人工）

质量控制：人工抽检10%

训练集/验证集划分：样本量小，选择尽量“节约“的方式

3.核心方法（双路径独立）

O1：可解释特征工程

O2：对比学习（SimCSE） # 只有这一种无监督（其实是自监督）方法

4.基线系统

B0：词袋模型

B1：n-gram

B2：标点指纹

B3：TF-IDF

B4：word2vec（有神经网络，但CPU能跑）

B5：预训练编码器零样本（MiniLM）

B6：更大一点的编码器（如RoBERTa）+SimCSE

B7：小型LLM（Qwen3.5-4B）

B8：更大一点的LLM（Qwen3.5-9B）

B9：云端API（DeepSeek）

B10：云端API（Kimi）

5.测试集构建

脱敏的原台词（70句）+其他文本（70句）	

其他游戏角色：25句（同域混淆）	

学术/哲学文本：25句（跨域+含"语义"等关键词）

仿写：20句（风格相似但非原文）	

手工风格梯度测试

压力测试：含专有词但没意义+边缘输入（比如单个标点符号）+对抗样本

人类基准制定：从不同的玩家群体分层抽几个人打分，之后进行一致性检验

6.评估体系

输入消融实验：用还原的测试集，如果这个方法差异巨大就踢掉

>注：本项目所称“消融实验“均指输入层的词汇消融（Input/Lexical Ablation），不是一般意义上“拆除组分测试”的消融实验，特此说明。
